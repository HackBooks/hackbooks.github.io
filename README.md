# 🛡️ HackBook --- Your Open-Source Cybersecurity & CTF Toolbox

Search, browse, and add security tools --- all in one place.\
HackBook is designed for ethical hackers, CTF players, cybersecurity
learners, and professionals who want a fast, organized way to discover
and manage security tools.

------------------------------------------------------------------------

## 🚀 What is HackBook?

HackBook is a lightweight, open-source platform where you can:

-   🔍 Search cybersecurity tools instantly\
-   📚 Browse categorized tools\
-   ➕ Add new tools to build the knowledge base\
-   🎯 Use as your personal CTF & hacking toolbox

A central hub for everything security-related --- optimized for speed
and simplicity.

------------------------------------------------------------------------

## ⭐ Features

-   🧰 Centralized Security Toolbox\
-   ⚡ Fast search with clean UI\
-   🏷️ Tools organized by category\
-   📝 Add new tools with metadata\
-   🌐 Open-source --- community-driven\
-   🔐 Focused on ethical hacking & learning

------------------------------------------------------------------------

## 🛠️ How to Add New Tools

1.  Click **Add Tool**
2.  Enter:
    -   Tool Name\
    -   Category\
    -   Description\
    -   Source/URL\
3.  Submit --- and it becomes searchable instantly.
